## Objetivo

Jogue todas as cartas: se ainda houver inimigos, você perde. Ao derrotar o último inimigo, você vence imediatamente. Pressione R para reiniciar.
Ao ser resolvida, a carta de Magia aplica seu bônus e desaparece em chamas, liberando a posição no tabuleiro.

Na tela inicial, pressione espaço para avançar pelos três parágrafos e revelar o menu. Selecione "Novo jogo" e pressione espaço após a introdução para começar. Após uma vitória ou derrota, pressione espaço para avançar pelos dois parágrafos até a tela final. R continua disponível para reiniciar durante o jogo e após o resultado.

Passe o cursor sobre as cartas para ver o efeito metalizado; cartas no tabuleiro também aumentam de tamanho.
Uma prévia ampliada aparece e desaparece em uma animação de vento, com a descrição à direita do tabuleiro. Ajuste `preview_offset` no nó `HUD/CardTooltip` para mudar sua posição.

Os textos exibidos no jogo podem ser editados em `data/text.cfg`.
O arquivo é incluído no pacote da exportação Web; exporte o jogo novamente após alterar os textos.
